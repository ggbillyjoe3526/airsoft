# Power-source models

The menus' pictures of the power sources as `<file>.glb` (glTF binary): the Standard Battery, the 11.1 V LiPo Battery
and the gas bottle, whose `Label` material is painted per gas (RM3), and the spring, its wire painted per spring (SN1);
all four rebuilt from the owner's photos in BL7, by the scripts in `tools/blender/power/`. Menu pictures only: they never show in a match.
Which power source draws from which file is `POWER_SOURCE_FILE` in `legacy/browser/src/config/assets.ts` (the browser game). How to make them:
[docs/CC0_ASSETS.md](../../../docs/CC0_ASSETS.md) › Power-source models. Record every file in
[docs/ASSETS.md](../../../docs/ASSETS.md).
