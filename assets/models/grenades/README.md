# Grenade models

The smoke and flash bombs as they show in a match (BL9): `smoke.glb` (the M18-style canister with its lever and pull
ring) and `flash.glb` (the pull-ring tube), built from the owner's photos by `tools/blender/grenades/grenades.py`,
unbranded. `game/play/grenade_view.gd` draws them thrown, landed and in hand, their `Kind` material painted in the
bomb's own colour. How to make them: [docs/CC0_ASSETS.md](../../../docs/CC0_ASSETS.md) › Grenade models. Record every
file in [docs/ASSETS.md](../../../docs/ASSETS.md).
